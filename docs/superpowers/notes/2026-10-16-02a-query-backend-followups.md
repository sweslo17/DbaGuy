## Frontend contracts for plans 02b / 02c

- Transaction state comes only from `session_state` events (one arrives on attach, one before every `finished`, one at every pause). Ignore `finished.in_transaction` for the badge.
- Refresh the schema with `POST /metadata/schema/refresh {profile_id}` only (no database), and always pass the session's database to completion/describe/search.
- `/sql/complete` should receive only the statement (or a window) around the cursor; whole 100 KB scripts cost > 50 ms.
- `ErrorPosition.column` is in UTF-16 code units — use JS `.length`, not `Array.from(...).length` (① console's `originOf` is wrong; the console is replaced in ②c).
- Reason codes are typed enums (`DangerReason`, `GuardReason`); map them to UI text in one place.
- Manual-commit mode: a SELECT opens a transaction on both engines; switching back to auto-commit needs commit/rollback first (`transaction_open`). A failed first statement leaves an empty open transaction.
- Read-only profiles reject multi-statement text (`read_only_single_statement`): always send one statement per execute.
- Expose the profile `safety` level (relaxed/standard/strict) in the connection dialog.
- Workspace tab kinds: query, table, object.
